# Kotlin 简明介绍

这是我在天津科技大学《移动终端程序设计》课堂上制作的一个简单介绍 Kotlin 的演示文稿（slides）。

## 关于本项目

本项目使用 [Typst](https://typst.app/) 制作演示文稿，主要内容包括：

- Kotlin 的优势（简洁性、可读性、空安全等）
- Kotlin 与 Java 的互操作性
- Kotlin 在 Android 开发中的应用

## 使用方法

1. 安装 Typst
2. 编译演示文稿：
   ```bash
   typst compile main.typ
   ```
